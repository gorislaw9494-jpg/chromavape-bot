# 🛍 Telegram-магазин с админ-панелью

Бот-магазин на **Python 3.12 + aiogram 3 + SQLite**. Три категории товаров:
**Жидкости**, **Под системы**, **Расходники**. Админ управляет товарами и
заказами прямо в боте.

## Возможности

### Для покупателя
- 🛍 Каталог по трём категориям с постраничным выводом
- 📄 Карточка товара: фото, описание, цена, наличие
- 🧺 Корзина: добавление, изменение количества, удаление
- 🧾 Оформление заказа **в один клик** — покупатель ничего не заполняет,
  данные берутся из Telegram
- 📦 История своих заказов и их статусы

### Для администратора (внутри бота)
- ➕ Добавление товара вручную: категория, название, цена, описание, фото, остаток
- ✏️ Редактирование любого поля товара, скрытие/показ, удаление
- 🔔 **Мгновенное уведомление о каждом новом заказе**
- 🧾 Управление заказами: принять → отправить → завершить / отменить
  (при отмене остатки возвращаются на склад)
- 📊 Статистика: пользователи, товары, заказы по статусам

## Быстрый старт

1. Установите Python 3.12 (если ещё нет).
2. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
3. Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot).
4. Скопируйте `.env.example` в `.env` и заполните:

   ```
   BOT_TOKEN=123456:ABC...
   ADMIN_IDS=123456789
   SHOP_NAME=VapeShop
   SUPPORT_CONTACT=@your_support
   ```

5. Запустите бота:
   - Windows: двойной клик по **`run.bat`** (сам создаст окружение и поставит зависимости)
   - или вручную:

     ```
     python -m venv .venv
     .venv\Scripts\pip install -r requirements.txt
     .venv\Scripts\python bot.py
     ```

## Как пользоваться

- Покупатель: `/start` → Каталог → категория → товар → «В корзину» → Корзина →
  «Оформить заказ» → «Подтвердить».
- Админ: `/admin` → «Товары» → выбрать категорию → «Добавить товар» и заполнить
  по шагам. Новые заказы приходят уведомлением с кнопками управления.

## Структура проекта

```
bot.py            — точка входа, настройка бота и роутеров
config.py         — конфигурация из .env
database.py       — слой БД (SQLite): товары, корзина, заказы, статистика
keyboards.py      — inline-клавиатуры
utils.py          — вспомогательные функции и уведомления
filters.py        — фильтр IsAdmin
states.py         — FSM-состояния (добавление/редактирование товара)
handlers/
  user.py         — пользовательские сценарии
  admin.py        — админ-панель
```

## Статусы заказа

`new` (новый) → `accepted` (принят) → `shipped` (отправлен) → `completed` (выполнен),
либо `cancelled` (отменён) на любом этапе до завершения.

## Примечания

- Оплата не подключена: заказ оформляется как заявка, менеджер связывается с
  покупателем в Telegram.
- Файл базы данных `shop.db` создаётся автоматически при первом запуске.
